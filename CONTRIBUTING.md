# Contributing

First of all, welcome, and thanks for helping out!

## What Is This Repo For

Contrary to [jterrazz](https://github.com/jterrazz)'s
[`awesome-42`](https://github.com/jterrazz/awesome-42), this repo does not aim
at providing recommendations and snippets directly, but quality resources for
students instead.

Because this repo aims to be an 'awesome' list and not a student blog, you must
contribute links to existing resources, not direct recommendations. Remember,
there is no good way to implement a project, nor are there a bad ways.

## License

This project is licensed under [CC0](LICENSE.md). Work you do for this repo will
effectively be placer under public domain.

## Subjects

Sharing subjects or links to the subjects is forbidden. Such contributions will
be turned down by the maintainer.

## Pull Requests

Apart from the first section, feel free to recommend a project or resources to
the repo! Format your pull request however you want, I will reformat it anyway!
