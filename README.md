# Awesome 42 [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

<a href="https://42.fr"></a><img src="https://upload.wikimedia.org/wikipedia/commons/8/8d/42_Logo.svg" align="right" alt="42 Logo" width=100 /></a>

A curated list of the best resources in the 42 community.

<br>

[**42**](https://en.wikipedia.org/wiki/42_(school)) is a free private
institution of education in computer science, relying on alternative methods of
education, such as "peer-to-peer" learning.

Thorough the years, many cool projects have been created around 42. The goal of
this repo is not to list them all, but to curate a list of up-to-date, usable
and of quality resources. After all, this is an
[awesome](https://github.com/sindresorhus/awesome) list. Yes, there are fewer
links here than on some other lists, but **most of the other lists are very
outdated**.

_Please read the [contribution guidelines](CONTRIBUTING.md) before
contributing._

## Resources

### Intranet

- [1337Leets](https://www.1337leets.com) - XP calculator, ranking, peer finder
- [GCC](https://gcc.42.fr/) - Official RNCP calculator
- [Hacku RNCP](https://rncp.hacku.org/rncp) - Third-party RNCP calculator
- [Improved Intra](https://github.com/FreekBes/improved_intra) - Extension to
  improve the intranet, incompatible with v3
- [42 Hub](https://apps.apple.com/us/app/42hub/id6754294085) - iOS companion app

### Text Editors/IDEs

- [42-header-oneshot](https://github.com/nakamo326/42-header-oneshot) - Add the
  42 header in multiple files at the same time
- [Makefile Template](https://github.com/tkomatsu/makefile) - A repo containing
  a template Makefile
- [Norminette](https://github.com/42School/norminette) - Official school linter
- [nicenorm](https://github.com/abeaugustijn/nicenorm) - Clearer Norminette
  output
- [nform](https://github.com/sickl8/nform) - Clearer Norminette output
- [norme.nvim](https://github.com/vinicius507/norme.nvim) - NeoVim plugin for
  the school norm
- [norminette-vim](https://github.com/alexandregv/norminette-vim) - Vim plugin
  for the school norm
- [c_formatter_42](https://github.com/dawnbeen/c_formatter_42) - Formatter that
  complies with the norm
- [c_formatter_42.vim](https://github.com/cacharle/c_formatter_42.vim) - Vim
  plugin for c_formatter_42

### Leakage Protection

- [Funcheck](https://github.com/froz42/funcheck) - Powerful malloc checker
- [valgrind_42](https://github.com/grouville/valgrind_42) - Dockerfile for quick
  correction that includes Valgrind, Vim and Clang
- [Valgrind for MacOS](https://github.com/LouisBrunner/valgrind-macos) -
  Valgrind builds for MacOS

### Fun

- [RP42](https://github.com/alexandregv/RP42) - Discord Rich Presence for 42
  students
- [42 Project Badges](https://github.com/ayogun/42-project-badges) - Pretty
  hand-made SVG badges to decorate project READMEs

### Documentation

- [42 Docs (unofficial)](https://harm-smits.github.io/42docs/) - Multiple
  projects, advanced MLX docs
- [CPPReference](https://en.cppreference.com/) - C and C++
- [Linux From Scratch](https://www.linuxfromscratch.org/) - Making a distro from
  scratch

### Help

- [StackOverflow](https://stackoverflow.com/c/42network/) - Questions asked by
  students and answered by students. Requires an intranet account.
- [Reddit](https://www.reddit.com/r/42_school/) - Unofficial

### Associations

- [La Contre-voie](https://lacontrevoie.fr/) - Ethics in computer science based
  in Angoulême

### Per-Campus

#### Lyon

- [Matrix](https://matrix.42lyon.fr/) - Find an empty seat in the clusters.
  Reserved to 42 Lyon students
- [42Eats ("Foyer")](http://www.42-eats.1site9.fr/) - Quickly buy food during
  your Piscine

### Advantages

You can leverage your student email to register to the following products for
free.

- [GitHub Students Pack](https://education.github.com/benefits) - GitHub Pro,
  Copilot, many third-party services
- [Office 365 Education (Student Developer Pack)](https://www.microsoft.com/en/education/products/office) -
  Office tooling
- [JetBrains Student Pack](https://www.jetbrains.com/academy/student-pack/) -
  IDEs, can also be claimed with GitHub Student Pack
- [LucidChart](https://www.lucidchart.com/pages/usecase/education) - Diagrams

#### Other

- [Choose A License](https://choosealicense.com/) - Choose a license when
  exposing your projects to the web
- [Homebrew](https://brew.sh/) - Package Manager for MacOS
- [Cleaner_42](https://github.com/ombhd/Cleaner_42) - Quick script to free up
  storage (might not have been made for your campus's file architecture,
  double-check)
